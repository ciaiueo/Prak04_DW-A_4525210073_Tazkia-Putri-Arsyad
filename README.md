# Arunika Studio

Project praktikum Desain Web dengan studi kasus landing page Arunika Studio.

## Deskripsi

Arunika Studio adalah landing page sederhana yang dibuat menggunakan HTML dan CSS. Website ini terdiri dari header, hero, layanan, dan footer.

Pada tugas ini saya menerapkan box model, class reusable, dan responsive design.

## Teknologi yang Digunakan

- HTML
- CSS
- Visual Studio Code
